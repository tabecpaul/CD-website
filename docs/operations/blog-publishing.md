# Career Direct Korea 블로그 운영 절차

## 발행 전 확인

- 제목은 독자의 현실 질문을 분명히 담고 90자 이내로 작성합니다.
- 설명은 검색 결과만 읽어도 글의 효용이 보이도록 180자 이내로 작성합니다.
- 건강·통계·정책·연구 주장은 1차 또는 공신력 있는 원문 자료로 확인합니다.
- 다른 사이트의 문장을 복사하지 않고 사실을 재구성해 설명합니다.
- 글마다 카드 6~10개, 실천 체크리스트, CTA 하나를 포함합니다.
- 고객 사례는 서면 동의와 비식별화를 완료한 경우에만 게시합니다.

## 발행 흐름

1. MDX 글을 작성하고 registry에 등록합니다.
2. `npm run lint --workspace=www`와 `npx tsc --noEmit -p apps/www/tsconfig.json`을 실행합니다.
3. Preview에서 데스크톱·모바일·카테고리·관련 글·CTA 링크를 확인합니다.
4. OG 이미지 주소 `/api/blog/og/{slug}`가 정상인지 확인합니다.
5. 승인 후 main에 병합하고 실제 도메인에서 한 번 더 확인합니다.

## 성과 확인

관리자 전환 분석에서 글별 조회, 카드 상호작용, 관련 글 이동, 자가진단 및 콜백 CTA를 확인합니다. 조회수만으로 판단하지 않고 CTA 전환과 상담 품질을 함께 봅니다.
