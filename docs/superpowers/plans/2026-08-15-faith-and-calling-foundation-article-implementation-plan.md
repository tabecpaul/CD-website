# 신앙과 소명 대표 글 구현 계획

1. 대한성서공회 공식 본문에서 핵심 구절의 장·절과 개역개정·새번역 문구를 확인한다.
2. 기존 블로그 컴포넌트를 사용하는 `calling-is-more-than-a-job.mdx`를 작성한다.
3. 글을 `faith-and-calling`, `published`, `featured`, `callback`으로 설정한다.
4. 블로그 레지스트리에 새 글과 메타데이터를 등록한다.
5. 린트와 프로덕션 빌드로 MDX·메타데이터·정적 경로를 검증한다.
6. 카테고리와 상세 페이지를 모바일·데스크톱에서 확인한다.
7. 신규 글·레지스트리·계획 파일만 커밋하고 기존 사용자 파일을 보존한다.
