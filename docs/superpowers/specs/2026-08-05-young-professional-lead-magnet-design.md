# Career Direct Korea 청년 직장인 리드 마그넷 랜딩페이지 설계

- 상태: 사용자 승인 완료
- 작성일: 2026-08-05
- 대상: 청년 직장인
- 1차 목표: 이메일 리드 확보
- 핵심 전환: 무료 진로방향 자가진단 PDF 신청
- 목표 전환율: 고유 랜딩페이지 방문 대비 유효 이메일 등록 20%
- 제외: 구현 코드, DB DDL, 공급자 프로비저닝, 전체 참여자 포털

## 1. 목적과 성공 기준

첫 릴리스는 청년 직장인이 진로 불안과 번아웃을 자신의 의지 부족이 아닌 진로 정렬 문제로 바라보고, 부담 없이 이메일을 등록해 무료 진로방향 자가진단 PDF를 받도록 하는 단일 전환 여정이다.

주요 성공 지표는 `lead_capture_succeeded / unique_landing_viewed`이며 목표는 20%다. 봇과 동일 사용자의 중복 제출은 전환율 계산에서 제외한다.

보조 지표는 다음과 같다.

- Hero 폼 시작률
- 폼 제출 성공률과 오류율
- PDF 다운로드율
- 격일 3회 코칭 이메일 전달·열람·CTA 클릭률
- 수신 거부율
- Career Direct 평가 관심 클릭률
- 상담 관심 클릭률

## 3. 콘텐츠 자산 구분

워크숍용 전체 워크북은 46페이지로 다음 내용을 포함한다.

- 한국 청년의 진로 현실과 AI 시대 변화
- 성격·흥미·재능·가치관의 네 나침반
- 네 나침반 통합과 정렬도
- Career Direct 평가 소개
- 보고서와 컨설턴트 해석
- 3개월·1년·5년 SMART 실행계획
- 지원 네트워크와 30일 실천

무료 리드 마그넷은 전체 워크북을 대체하지 않는 8~12페이지 요약 자가진단 PDF다. 현실 인식과 네 나침반의 핵심 질문을 제공해 사용자가 더 확인해야 할 영역을 발견하도록 돕는다. 워크숍 전용 심층 워크시트, 전체 실행계획, 상세 해석 자료는 포함하지 않는다.

무료 PDF와 전체 워크숍의 관계는 다음처럼 표현한다.

- 무료 PDF: 현재 상태와 핵심 질문을 발견하는 첫걸음
- Career Direct 워크숍: 평가, 보고서 해석, 실행계획과 후속 코칭을 포함하는 완전한 여정

## 4. 사용자 여정

1. 청년 직장인이 캠페인 또는 검색을 통해 `/career-check`에 방문한다.
2. Hero의 질문과 설명을 읽고 자신의 문제와 연결한다.
3. 이메일 주소와 필요한 동의를 제출한다.
4. 서버가 입력, 동의, 중복 여부, 속도 제한을 검증한다.
5. 리드와 동의가 PostgreSQL에 저장된다.
6. 감사 페이지에서 만료되는 PDF 링크를 즉시 제공한다.
7. 자료 전달 이메일로 같은 PDF 링크를 발송한다.
8. 2일 차, 4일 차, 6일 차에 이메일 미니 코칭을 한 번씩 발송한다.
9. 세 번째 코칭 이메일에서 Career Direct 평가를 주 CTA로, 컨설턴트 상담을 보조 CTA로 제시한다.

## 5. 메시지와 콘텐츠 구조

### 5.1 Hero

- Eyebrow: `청년 직장인을 위한 무료 진로방향 자가진단`
- 제목: `왜 열심히 사는데 진로 불안과 번아웃을 느끼나요?`
- 설명: `문제는 의지가 부족해서가 아니라, 나에게 맞는 방향과 현재의 일이 어긋나 있기 때문일 수 있습니다. 10분 자가진단으로 지금 점검해야 할 질문을 찾아보세요.`
- CTA: `무료 진로방향 자가진단 받기`
- 보조 문구: `즉시 다운로드 · 격일 3회 이메일 미니 코칭 · 언제든 수신 거부`

Hero는 데스크톱에서 메시지와 폼을 나란히 배치하고 모바일에서는 메시지 다음에 폼이 바로 나타나는 전환 집중형을 사용한다.

### 5.2 현실 인식

- 진로 불안
- 번아웃
- 직무 불일치

검증된 핵심 통계 3개만 사용한다. 각 통계는 기관명만 표시하지 않고 원문 링크, 조사 시점, 필요한 경우 표본을 제공한다. 결론은 `개인의 의지 문제가 아니라 방향과 일의 정렬 문제일 수 있다`로 연결한다.

### 5.3 무료 PDF 미리보기

- PDF 표지
- 실제 내부 페이지 일부
- 현재 상태 점검
- 불안의 원인 정리
- 다음 행동 발견

무료 PDF와 46페이지 워크숍용 전체 워크북이 다르다는 점을 명확히 표시한다.

### 5.4 네 가지 나침반

기존 사이트의 나침반 시각 구조를 재사용하되 문구는 다음으로 고정한다.

- 성격: 어떻게 일할 때 편안한가
- 흥미: 무엇에 자연스럽게 끌리는가
- 재능: 무엇을 잘하는가
- 가치관: 왜 그 일을 하는가

### 5.5 발견에서 실행까지 6단계

1. 현실 인식: 진로 불안, 직무 불일치, AI 변화를 이해한다.
2. 자가진단: 네 나침반으로 현재 상태를 점검한다.
3. Career Direct 평가: 네 요소를 하나의 시스템에서 심층 평가한다.
4. 보고서·컨설턴트 코칭: 공인 컨설턴트가 결과를 함께 해석한다.
5. 인터랙티브 실행계획: 3개월·1년·5년 목표와 장애물, 지원 네트워크를 디지털 계획으로 전환한다.
6. 이후 코칭: 진척 점검과 후속 코칭으로 계획을 실제 삶에 적용한다.

### 5.6 Career Direct 신뢰 요소

공식 자료로 확인된 사실만 사용한다. 평가 시간, 보고서 분량, 국가·언어·사용자·컨설턴트 수 등 변할 수 있는 수치는 발행 직전에 공식 출처에서 재확인한다. 확인되지 않은 성과 수치와 비교 우위 주장은 발행하지 않는다.

### 5.7 후기

청년 직장인의 실제 후기를 우선 사용한다. 당사자의 공개 사용 동의, 익명화 범위, 사용 채널이 확인되지 않으면 표시하지 않는다. 검증된 후기가 없는 초기 릴리스에서는 후기 섹션 자체를 제외한다.

### 5.8 FAQ

- 무료 PDF와 Career Direct 평가는 어떻게 다른가
- 이메일은 어떻게 사용되는가
- 격일 3회 코칭 이메일에는 무엇이 포함되는가

- 신앙이 없어도 이용할 수 있는가

### 5.9 최종 CTA와 Footer

페이지 하단에 Hero와 동일한 이메일 폼을 반복한다. 상담 신청 폼은 랜딩페이지에서 제거하고 이메일 여정 후반의 보조 CTA로 이동한다.

- 공개 사이트: `https://www.careerdirect.kr`
- Career Direct 온라인 평가 CTA: `https://www.careerdirect.org/`
- Footer 주소: `경기도 의왕시 오봉산단1로 12, 에이스비전 21 10층 1012호`
- 컨설턴트 상담은 실제 목적지 URL이 확정된 뒤 연결한다.

Footer에는 실제 승인 로고, 개인정보처리방침, 수신 거부, 공식 문의처, 필요한 상표·저작권 표시를 제공한다.

- 실제 발송

PostgreSQL이 리드와 동의의 유일한 원본이다. Cron, Edge Functions, AWS SES는 실행 시스템이며 고객 상태를 최종 결정하지 않는다. n8n은 첫 출시에서 제외하고 복수 고객 여정과 외부 시스템 연결이 늘어날 때 서울 리전 자체 호스팅 방식으로 재검토한다.

## 7. 리드와 동의 데이터

첫 폼에서 수집하는 값은 다음으로 제한한다.

- 정규화된 이메일 주소
- 서비스 제공을 위한 개인정보 처리 동의
- 격일 3회 이메일 미니 코칭 수신 동의
- 동의 정책 버전과 동의 시각
- 유입경로와 UTM
- 랜딩페이지·폼 버전
- 서버가 생성한 익명 방문·세션 식별자

이름, 전화번호, 커리어 고민은 첫 폼에서 받지 않는다.

서비스 제공 동의와 마케팅 수신 동의의 필수·선택 여부와 문구는 발행 전 개인정보 정책 결정 문서 및 법률 검토 결과에 맞춘다. 제품은 두 목적을 별도 동의 레코드로 저장할 수 있어야 한다.

## 8. 제출과 중복 처리

1. 브라우저와 서버에서 이메일 형식을 검증한다.
2. 서버에서 동의, 요청 빈도, 봇 방지 필드를 검증한다.
3. 이메일을 정규화하고 기존 리드를 조회한다.
4. 신규 리드는 리드·동의·유입·Outbox를 하나의 트랜잭션으로 기록한다.
5. 기존 리드는 새 레코드를 만들지 않고 유입 이력과 명시적 동의 변경만 기록한다.
6. 과거 수신 거부 사용자는 새 명시적 동의가 확인된 경우에만 다시 등록한다.
7. 저장 성공 후에만 성공 응답과 감사 페이지를 제공한다.

## 9. 이메일 미니 코칭 일정

### 등록 즉시: 자료 전달

- PDF 다운로드 링크
- PDF 활용 방법
- 격일 3회 코칭 일정 고지
- 수신 거부 링크

### 2일 차: 코칭 1

- 주제: 지금의 진로 불안과 에너지 소진 원인 돌아보기
- 형식: 성찰 질문 1개와 행동 1개

### 4일 차: 코칭 2

- 주제: 성격·흥미·재능·가치관 중 가장 어긋난 나침반 찾기
- 형식: 성찰 질문 1개와 행동 1개

### 6일 차: 코칭 3

- 주제: 다음 30일의 작은 행동 정하기
- 형식: 성찰 질문 1개와 행동 1개
- 주 CTA: Career Direct 평가 알아보기
- 보조 CTA: 컨설턴트와 상담하기

자료 전달 메일은 코칭 3회에 포함하지 않는다. 사용자가 이메일을 열지 않았다는 이유로 추가 발송하거나 간격을 앞당기지 않는다. 모든 이메일에 즉시 작동하는 수신 거부 링크를 포함한다.

## 10. 오류와 복구

- 잘못된 이메일: 필드 아래 구체적인 한국어 오류를 표시한다.
- 동의 누락: 필요한 동의와 선택 가능한 동의를 구분해 설명한다.
- 중복 제출: `이미 등록된 이메일입니다. 자료를 다시 보내드렸습니다`라고 안내하되 실제 재발송 성공 여부에 맞춰 문구를 결정한다.
- 데이터베이스 장애: 성공 화면을 표시하지 않고 안전한 재시도를 안내한다.
- 이메일 발송 장애: 리드는 유지하고 자동 재시도 후 운영자에게 알린다.
- PDF 링크 만료: 이메일 소유 확인 후 새 링크를 발급한다.
- 중복 웹훅: idempotency key로 한 번만 상태를 변경한다.
- 봇과 남용: honeypot, 요청 속도 제한, 서버 검증을 적용한다.

오류 로그에는 이메일 원문을 남기지 않는다. 필요한 경우 비가역 해시 또는 내부 식별자를 사용한다.

- 실제 승인 로고
- 개인정보처리방침과 공식 문의처

핵심 검색 의도는 `청년 직장인 진로 고민`, `진로 불안`, `직무 불일치`, `커리어 방향`, `진로 자가진단`이다. 키워드를 반복 삽입하지 않고 사용자의 질문에 자연스럽게 답한다.

## 13. 접근성과 모션

- 모바일 360px 이상에서 가로 스크롤이 없어야 한다.
- 모든 입력은 보이는 label과 오류 설명을 가진다.
- 키보드만으로 폼 제출과 정책 링크 접근이 가능해야 한다.
- 색상만으로 상태를 전달하지 않는다.
- CTA와 본문 대비는 WCAG AA를 목표로 한다.
- `prefers-reduced-motion` 사용자는 등장 애니메이션 없이 콘텐츠를 볼 수 있어야 한다.
- JavaScript 실행 실패 시에도 핵심 콘텐츠는 서버 렌더링되어 읽을 수 있어야 한다.

- 중복 웹훅과 재시도
- 수신 거부 후 후속 발송 차단

- 오류 후 입력값 보존

- 전환율 20%를 측정할 분석 분모와 분자가 정의대로 집계된다.

- 섹션 단위 React 컴포넌트 구조
- Pretendard 중심 한국어 타이포그래피
- 네이비·크림·골드·틸 색상 체계

- FAQ 아코디언 구조

다음 요소는 교체하거나 제거한다.

- 존재하지 않는 앵커 링크

## 16. 구현 순서

1. 개인정보·동의 문구와 공급자 결정을 기록한다.
2. 무료 8~12페이지 PDF의 콘텐츠와 최종 파일을 승인한다.
3. 랜딩페이지 라우트와 서버 렌더링 콘텐츠를 구현한다.
4. 리드·동의·유입·Outbox 데이터 계약을 구현한다.
5. 이메일 폼과 오류·중복 처리 흐름을 구현한다.
6. 감사 페이지와 만료 PDF 링크를 구현한다.
7. 자료 전달 및 격일 3회 이메일 자동화를 연결한다.
8. 분석 이벤트와 전환 대시보드를 연결한다.
9. 접근성, 반응형, 장애, 개인정보, 이메일 전달을 검증한다.
10. 제한된 트래픽으로 출시하고 20% 전환 목표를 측정한다.
