# Career Direct 검사 20분 무료 콜백 퍼널 설계

## 1. 목적

Career Direct Korea의 무료 자가진단과 격일 3회 코칭을 경험한 사용자가 검사에 관심을 보이는 순간 미국 본부 사이트로 이탈하지 않고, Career Direct Korea 컨설턴트와 직접 연결되도록 전환 구조를 변경한다.

핵심 여정은 다음과 같다.

`PDF QR·웹 CTA·3회차 이메일 → 전용 검사 상담 페이지 → 20분 무료 콜백 신청 → 콜백 → 상품 확정 → 고객별 결제 안내 → 결제 확인 → 본부 평가 시스템에서 검사 진행 → 보고서 해석 컨설팅`

본부 한국어 사이트는 신뢰와 공식 정보 확인을 위한 보조 경로로 유지한다. 검사 신청과 진행의 주 경로는 Career Direct Korea가 소유한다.

## 2. 전환 원칙

- 구매 의도가 있는 모든 주 CTA는 `20분 무료 콜백 신청하기`로 통일한다.
- 신청만으로 결제되거나 검사가 시작되지 않는다고 바로 안내한다.
- 본부 한국어 사이트 링크는 `공식 정보 둘러보기`라는 보조 CTA로 분리한다.
- 콜백 신청부터 결제·평가 진행까지 1인 운영자가 내부 대시보드에서 관리한다.
- 초기 결제는 상담 후 고객별 결제 안내 링크를 이메일 또는 문자로 발송한다.
- PG사가 확정되기 전에는 사이트에서 카드정보를 수집하거나 실제 카드 결제를 처리하지 않는다.

## 3. 유입 경로

다음 경로의 주 CTA를 Career Direct Korea 내부로 연결한다.

- 랜딩페이지의 검사 관심 CTA
- 「진로방향 자가진단」 PDF 하단 QR과 클릭 링크
- 3회차 코칭 이메일의 검사 CTA
- 향후 블로그와 캠페인 랜딩페이지의 검사 CTA

내부 목적지는 `/assessment-consultation`이다. 현재 PDF QR 경유 경로 `/go/assessment?source=pdf_qr`는 익명 클릭을 기록한 뒤 본부 사이트가 아니라 `/assessment-consultation`로 이동한다.

전용 페이지에서 본부 한국어 사이트 `https://careerdirect.org/?language_code=KO`를 보조 링크로 제공한다.

## 4. 전용 검사 상담 페이지

### 4.1 콘텐츠 구조

1. Career Direct 검사가 필요한 이유
2. 20분 무료 콜백에서 안내하는 내용
   - 검사 적합성
   - 평가·보고서·해석 컨설팅 과정
   - 예상 일정과 비용
   - 결제 후 검사 진행 방법
3. 신청만으로 결제되거나 검사가 시작되지 않는다는 안내
4. 콜백 신청서
5. 본부 한국어 사이트의 공식 정보를 확인하는 보조 링크

### 4.2 CTA 문구

주 CTA:

> 20분 무료 콜백 신청하기

보조 설명:

> Career Direct 검사 적합성, 진행 과정과 비용을 1:1로 안내해 드립니다. 신청만으로 결제되거나 검사가 시작되지 않습니다.

PDF QR 주변 문구:

> 검사가 궁금하다면 QR을 스캔해 20분 무료 콜백을 신청하세요.

완료 화면:

> 콜백 신청이 접수되었습니다. 영업일 기준 1일 이내에 연락드려 20분 통화 시간을 확정하겠습니다.

## 5. 콜백 신청 정보

### 5.1 필수 항목

- 이름
- 휴대전화
- 이메일
- 희망 날짜
- 희망 시간대
  - 오전 9시–12시
  - 오후 12시–6시
  - 저녁 6시–9시
- 상담 주제 최소 1개
  - 진로 불안
  - 이직 고민
  - 진로 변경
  - 경력단절 후 재취업
  - 기타
- 개인정보 수집·이용 동의

### 5.2 응답 선택 항목

빈값 대신 명시적 `응답하지 않음`을 제공한다.

- 성별: 남성 / 여성 / 응답하지 않음
- 연령대: 20–24 / 25–29 / 30–34 / 35–39 / 40–49 / 50세 이상 / 응답하지 않음
- 혼인 여부: 미혼 / 기혼 / 응답하지 않음
- 기타 상담 주제를 선택한 경우 짧은 직접 입력란
- 마케팅 정보 수신 동의

성별·연령대·혼인 여부는 각 항목에서 하나를 선택하되 `응답하지 않음`을 기본 선택지로 제공한다. 상담 주제는 복수 선택이다.

### 5.3 검증

- 서버가 모든 허용값을 다시 검증한다.
- 이메일과 국내 휴대전화 형식을 검증한다.
- 희망 날짜는 한국시간 기준 오늘부터 60일 이내여야 한다.
- `기타` 내용은 길이를 제한하고 기타 선택 시에만 허용한다.
- 개인정보 필수 동의가 없으면 접수하지 않는다.
- 짧은 시간 내 동일 요청의 중복 제출을 방지한다.

## 6. 접수 알림

신청 저장 후 두 통의 이메일을 Resend로 발송한다.

### 6.1 관리자 알림

수신자: `dulospaul@gmail.com`

포함 정보:

- 신청자 이름
- 전화번호
- 희망 날짜·시간대
- 선택한 상담 주제
- 관리자 상세보기 링크

이메일에 불필요한 상세 개인정보를 모두 복제하지 않는다.

### 6.2 고객 확인

- 접수 완료
- 영업일 기준 1일 이내 연락
- 20분 통화에서 검사 적합성·진행 과정·비용을 안내한다는 설명
- 신청만으로 결제나 검사가 시작되지 않는다는 안내

이메일 실패는 신청 데이터를 삭제하지 않는다. 관리자 화면에서 알림 상태를 확인하고 재발송할 수 있게 한다.

## 7. 1인용 검사 상담 CRM

기존 관리자 로그인 아래에 검사 상담 목록과 상세 화면을 추가한다.

### 7.1 상태

1. `new` — 신규 신청
2. `scheduled` — 콜백 일정 확정
3. `callback_completed` — 콜백 완료
4. `payment_sent` — 결제 안내 발송
5. `paid` — 결제 완료
6. `assessment_in_progress` — 평가 진행
7. `consulting_completed` — 컨설팅 완료
8. `on_hold` — 보류/종료

상태를 건너뛸 수는 있지만, `paid`와 `assessment_in_progress`는 관리자가 실제 확인한 뒤에만 수동으로 변경한다.

### 7.2 목록

- 이름
- 전화번호
- 이메일
- 희망 날짜·시간대
- 상담 주제
- 신청일
- 현재 상태
- 신규/미처리 강조

### 7.3 상세

- 신청 정보 전체
- 상태 변경
- 상태 변경 시각
- 운영 메모
- 관리자·고객 이메일 발송 상태
- 이메일 재발송

운영 메모에는 건강·종교·가족관계 등 콜백 운영에 불필요한 민감정보를 적지 않도록 안내한다.

## 8. 결제와 검사 진행

콜백 후 검사가 확정되면 관리자는 상태를 `payment_sent`로 변경하고 고객별 결제 안내 링크를 이메일 또는 문자로 발송한다. 결제 확인 후 `paid`, 검사 접근 정보를 전달한 후 `assessment_in_progress`로 변경한다.

현재 `/checkout`의 임시 가격과 가짜 결제 UI를 공개 검사 신청 경로에 사용하지 않는다. 상품·가격·PG사가 확정될 때 별도의 결제 설계를 진행한다.

## 9. 분석

### 9.1 이벤트

- `callback_cta_clicked`
- `callback_submitted`
- `official_site_clicked`

기존 `assessment_cta_clicked`의 과거 데이터 의미를 바꾸지 않는다.

### 9.2 출처

- PDF QR: `pdf / qr / career_direction_check`
- 랜딩페이지: 기존 방문 UTM과 CTA 위치 유지
- 3회차 이메일: `email / coaching / coaching_3`
- 직접 유입: `(direct)`

### 9.3 퍼널

전체 운영 퍼널:

`고유 방문 → PDF 신청 → PDF 다운로드 → 콜백 CTA 클릭 → 콜백 신청 → 콜백 완료 → 결제 안내 → 결제 완료 → 평가 진행`

초기 대시보드 핵심 지표:

- 콜백 CTA 클릭
- 콜백 신청
- CTA→신청 전환율
- 신규/미처리 신청
- 결제 완료
- 평가 진행

본부 공식 정보 링크 클릭은 구매 의도 클릭과 별도로 집계한다.

분석 실패는 신청 저장, 접수 이메일이나 페이지 이동을 차단하지 않는다.

## 10. 데이터 모델

새 `assessment_callback_requests` 테이블을 사용한다. 기존 `consultation_requests`는 일반 무료 진로상담 데이터와 기존 화면의 호환성을 위해 그대로 유지한다. 두 테이블을 자동 병합하거나 과거 일반 상담을 검사 콜백으로 간주하지 않는다.

필요 데이터:

- 신청자 연락처
- 희망 날짜·시간대
- 인구통계 선택값
- 상담 주제 배열과 기타 내용
- 개인정보·마케팅 동의 및 동의 버전
- 유입 UTM과 CTA 위치
- 운영 상태 및 상태 변경 시각
- 관리자 메모
- 관리자·고객 이메일 발송 상태와 오류 코드
- 생성·수정 시각

분석 이벤트에는 이름, 이메일, 전화번호, 신청 ID를 복제하지 않는다.

## 11. 개인정보와 보안

- 필수정보: 이름, 휴대전화, 이메일, 희망 날짜·시간대, 상담 주제
- 선택정보: 성별, 연령대, 혼인 여부, 기타 상담 내용
- 보유기간: 상담 종료 후 3년 또는 삭제 요청 시까지
- 마케팅 사용은 별도 선택 동의가 있는 경우에만 허용한다.
- 결제수단 정보는 저장하지 않는다.
- 관리자 목록과 상세는 현재 1인용 관리자 세션에서만 접근한다.
- 개인정보처리방침과 동의 문구에 새로운 수집 항목·목적·보유기간을 반영한다.
- 운영 로그와 관리자 알림에는 비밀번호, 토큰, 카드정보를 남기지 않는다.

## 12. 오류 처리

- DB 저장 실패 시 성공 화면을 표시하지 않는다.
- 관리자 알림 실패 시 신청을 유지하고 재발송 가능한 실패 상태를 남긴다.
- 고객 확인 이메일 실패 시 신청을 유지하고 관리자 상세에서 확인한다.
- 상태 변경 실패 시 이전 상태를 유지한다.
- 잘못된 입력은 항목별 오류 메시지로 안내한다.
- PDF QR의 분석 기록 실패는 콜백 페이지 이동을 막지 않는다.

## 13. 출시 검증

1. PDF QR·웹 CTA·3회차 이메일이 콜백 신청 페이지로 이동한다.
2. 본부 한국어 사이트가 보조 링크로 열린다.
3. 모바일과 데스크톱에서 신청 입력·검증·완료 화면이 동작한다.
4. 신청 DB 저장, 관리자 알림, 고객 확인 이메일이 동작한다.
5. 관리자 목록·상세·상태 변경·이메일 재발송이 동작한다.
6. 7/30/90일 분석 집계와 유입 출처가 구분된다.
7. 개인정보처리방침과 필수·선택 동의가 일치한다.
8. 결제되지 않은 신청이 평가 진행으로 자동 변경되지 않는다.
9. 새 PDF QR 문구·목적지·레이아웃을 확인한다.

## 14. 제외 범위

- PG사 실제 카드 결제 연동
- Career Direct 본부 평가 계정 자동 발급
- 본부 평가 사이트 내부의 진행·완료 이벤트 자동 수집
- SMS 발송 자동화
- 다중 컨설턴트 배정과 권한 관리
- 캘린더 시간 슬롯 자동 확정
