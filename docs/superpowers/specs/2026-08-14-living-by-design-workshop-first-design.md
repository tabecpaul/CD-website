# Living By Design 워크숍 우선 전환 설계

## 1. 목적

Career Direct Korea의 교육 콘텐츠와 유료 서비스를 하나의 자연스러운 고객 여정으로 연결한다. 승인된 1안인 **워크숍 우선형(Discovery First)**을 기준으로 삼아, 무료 자가진단·진로 특강·Living By Design 워크숍·Career Direct 평가·보고서 컨설팅의 역할이 중복되지 않게 구분한다.

핵심 원칙은 다음과 같다.

- 무료 자가진단은 아직 자기이해의 필요성을 충분히 느끼지 못한 잠재 고객의 첫 진입점이다.
- 90분 진로 특강은 문제 인식과 자기이해의 필요성을 만드는 교육형 진입점이다.
- Living By Design 워크숍은 참가자가 자신의 고유한 디자인을 발견하고 실행 방향을 세우는 심화 경험이다.
- 워크숍 참가자는 이미 평가 필요성을 이해한 단계로 간주하므로 무료 자가진단으로 되돌리지 않는다.
- 워크숍 이후의 주 전환은 Career Direct 평가와 보고서 컨설팅이다.

브랜드 캐치프레이즈는 모든 관련 콘텐츠에서 다음 문구로 통일한다.

> Discover Your Design. Discern Your Calling. Drive Your Journey.

## 2. 전체 고객 여정

### 2.1 일반 광고·검색 유입

`광고·검색·블로그 → 무료 12페이지 진로 방향 자가진단 → 후속 이메일 → 진로 특강 또는 20분 무료 콜백 → Career Direct 평가·보고서 컨설팅 → 실행계획 → 후속 컨설팅`

### 2.2 교회·대학·기관 유입

`기관 문의 → 90분 진로 특강 → 준비도에 따라 자가진단 또는 콜백 → Living By Design 워크숍 또는 Career Direct 평가·보고서 컨설팅`

### 2.3 Living By Design 워크숍 직접 참가

`워크숍 → 20분 무료 콜백 또는 평가 직접 신청 → Career Direct 평가 → 보고서 컨설팅 → 인터랙티브 실행계획 → 후속 컨설팅`

워크숍 참가자에게는 무료 자가진단을 다시 제안하지 않는다. 워크숍 자체가 현실 인식과 자기이해를 충분히 다루기 때문이다.

## 3. 콘텐츠 제품 구조

### 3.1 무료 12페이지 진로 방향 자가진단

- 대상: 자기이해 필요성에 대한 준비도가 낮거나 중간인 일반 잠재 고객
- 목적: 현실 인식과 네 가지 나침반에 대한 첫 이해
- 다음 단계: 격일 후속 이메일, 특강, 20분 무료 콜백
- 제한: Career Direct 공식 평가로 오해할 표현을 사용하지 않는다.

### 3.2 90분 진로 특강

두 버전을 동시에 운영한다.

#### 일반 청년 직장인 버전

- 진로 불안·번아웃·직무 불일치의 현실
- 방향 결정 전에 필요한 자기이해
- 성격·흥미·재능·가치관의 네 가지 나침반
- 작은 실험과 실행 방향
- 준비도가 낮은 참가자에게 자가진단, 높은 참가자에게 콜백 또는 평가 신청 안내

#### 기독 대학·교회 청년 버전

- 공통 내용 70%
- 소명, 청지기 정신, 성경적 일의 관점, 공동체 분별을 포함한 대상별 내용 30%
- 자신의 고유한 디자인과 부르심을 연결하되 검사 결과가 소명을 자동 결정한다고 표현하지 않는다.

별도의 4페이지 미니 워크시트는 제작하지 않는다. 특강 후 자가진단 또는 평가·컨설팅으로 이어지는 기존 흐름과 중복되기 때문이다.

### 3.3 Living By Design 워크숍

- 권장 시간: 2시간 40분~3시간
- 대상: 개인, 교회 청년부, 대학, 기관
- 자료: 기존 참가자 워크북과 진행자 자료를 재구성해 사용
- 목표: 단순 지식 전달이 아니라 자기 발견, 분별, 실행계획, 공동체 성찰을 경험하게 한다.

권장 진행 구성:

| 구간 | 시간 | 핵심 내용 |
|---|---:|---|
| 오프닝 | 10분 | 9만 시간의 의미와 워크숍 목표 |
| 현실 인식 | 20분 | 진로 불안, 번아웃, 직무 불일치 |
| 성공 기준 | 25분 | 외부 기준과 개인의 성공 기준 구분 |
| 고유한 디자인 | 30분 | 성격·흥미·재능·가치관 통합 |
| 일과 소명 | 25분 | 일반형은 의미·기여, 기독형은 성경적 일과 소명 |
| 작은 실험 | 25분 | 2주 실행 실험과 관찰 기준 |
| 공동체 성찰 | 25분 | 나눔, 피드백, 기독형은 기도와 분별 포함 |
| 다음 단계 | 10분 | Career Direct 평가·보고서 컨설팅 안내 |

워크숍에서 사용하는 활동지는 기존 워크북의 심화 활동으로 유지한다. 제거하는 것은 **특강용 별도 4페이지 미니 워크시트**뿐이다.

## 4. 평가·컨설팅 전환

워크숍 종료 CTA는 두 가지로 제한한다.

1. `Career Direct 평가·보고서 컨설팅 신청하기`
2. `20분 무료 콜백으로 먼저 확인하기`

본부 사이트는 공식 정보 확인용 보조 링크로만 제공한다. 실제 신청과 검사진행은 Career Direct Korea를 통해 연결한다.

평가 링크는 결제 확인 후 고객에게 발송한다. 고객이 링크를 통해 본부 시스템에 등록한 시점은 평가 크레딧을 사용하기 시작한 것으로 본다.

- 링크 발급 후 14일 이내이며 본부 등록 전: 취소 요청 시 링크 취소 가능
- 본부 등록 후: 환불 불가
- 공개 가격은 평가 단독 상품보다 평가와 3시간 보고서 컨설팅을 포함한 통합 패키지를 중심으로 안내

서비스 명칭은 `커리어 코칭`보다 `커리어 컨설팅`을 우선 사용한다.

## 5. 콜백 운영 설계

콜백이 1인 운영자의 시간을 과도하게 차지하지 않도록 신청 단계에서 상담 필요도를 분리한다.

### 선택 옵션

- 전화 상담: 15분
- Zoom 상담: 20분
- 상담 없이 평가 신청

### 운영 제한

- 하루 최대 상담 4건
- 일정 사이 10분 버퍼
- 예약 가능 시간만 노출
- 워크숍 참가자는 신청 화면에서 유입 유형을 자동 식별해 기본 설명을 반복하지 않는다.

Zoom은 라포 형성이 특히 필요한 고관여 고객에게 제공하고, 간단한 절차 확인은 전화로 처리한다. 이미 구매 의사가 높은 고객은 상담 없이 신청할 수 있게 한다.

## 6. 단계별 자동화

### 1단계 — 현재 운영

- 고객이 전화·Zoom·직접 신청 중 선택
- 관리자가 일정과 적합성을 확인
- 결제와 평가 링크 발급은 관리자가 최종 확인

### 2단계 — 일정 자동화

- 예약 가능 슬롯 자동 표시
- 중복 예약 방지
- Zoom 링크 자동 생성
- 예약 확인·24시간 전·1시간 전 알림
- 변경·취소 링크 제공

### 3단계 — 상담 업무 절감

- 신청 목적과 준비도에 따른 자동 분류
- 가격·절차·환불·평가 소요시간 FAQ 자동 안내
- 상담 전 요약 생성
- 상담 후 다음 단계와 운영 메모 자동 초안

결제 확인, 평가 링크 발급, 본부 등록 여부와 환불 가능 여부처럼 금전·권리 상태에 영향을 주는 작업은 자동화 이후에도 관리자 확인을 거친다.

## 7. 데이터와 분석

각 신청에 다음 유입 유형을 보존한다.

- `lead_magnet`
- `general_lecture`
- `christian_lecture`
- `living_by_design_workshop`
- `direct`

추가로 전화·Zoom·직접 신청 선택, 기관명, 프로그램 회차, UTM을 기록한다. 민감한 상담 내용은 마케팅 분석 데이터에 포함하지 않는다.

핵심 지표:

- 자가진단 신청률
- 특강 후 자가진단·콜백·평가 신청률
- 워크숍 후 콜백·평가 신청률
- 전화와 Zoom의 평가 확정률
- 콜백 없이 직접 신청한 비율
- 평가 완료율과 보고서 컨설팅 완료율
- 운영자 주간 상담 건수와 소요시간

## 8. 오류 처리와 운영 안전장치

- 분석 이벤트 실패가 신청 접수를 막지 않게 한다.
- 이메일·Zoom 링크 생성 실패 시 신청은 저장하고 관리자에게 재처리 항목을 표시한다.
- 하루 상담 한도를 넘으면 다음 가능한 일정을 제시한다.
- 중복 신청은 기존 고객 여부를 표시하되 자동 삭제하지 않는다.
- 일반형 참가자에게 기독교 표현이 잘못 노출되지 않도록 프로그램 버전을 명시적으로 저장한다.
- 워크숍 참가자에게 자가진단 CTA가 다시 노출되지 않도록 유입 유형별 다음 단계를 분기한다.

## 9. 검증 기준

1. 일반형과 기독형 특강의 공통 핵심은 같고 대상별 표현만 구분된다.
2. 특강 자료에 별도 4페이지 미니 워크시트가 포함되지 않는다.
3. 워크숍 종료 후 자가진단이 아닌 평가·컨설팅 CTA가 우선 노출된다.
4. 전화 15분, Zoom 20분, 상담 없는 신청이 각각 정상 접수된다.
5. 하루 최대 4건과 10분 버퍼가 일정에 적용된다.
6. 프로그램·회차·유입·상담 방식이 분석까지 보존된다.
7. 이메일 또는 Zoom 자동화 실패가 신청 데이터를 잃게 하지 않는다.
8. 결제·본부 등록·환불 상태는 관리자 확인 없이 변경되지 않는다.
9. 모바일·데스크톱에서 각 CTA의 의미와 다음 단계가 명확하다.
10. `고유한 설계` 대신 `고유한 디자인`, `커리어 코칭` 대신 문맥상 `커리어 컨설팅`을 사용한다.

## 10. 구현 범위 분리

한 번에 모든 기능을 구현하지 않는다.

### 콘텐츠 트랙

1. 일반형·기독형 90분 특강 구성안
2. Living By Design 워크숍 진행안
3. 참가자 워크북 정리
4. 진행자 가이드와 후속 CTA

### 제품·운영 트랙

1. 프로그램별 CTA와 유입 구분
2. 전화·Zoom·직접 신청 선택
3. 일정 한도와 버퍼
4. 분석 대시보드 확장
5. 일정·Zoom·알림 자동화

첫 구현 계획은 **콘텐츠 구조 확정과 신청 방식 분기**까지만 다룬다. 일정·Zoom 완전 자동화는 실제 운영 데이터를 확인한 뒤 별도 사양으로 확장한다.
