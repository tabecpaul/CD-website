# Career Direct 통합 패키지 무통장입금 퍼널 설계

## 1. 목적

20분 무료 콜백을 마친 고객이 Career Direct 평가·상세 보고서·3시간 집중 컨설팅을 하나의 통합 프로그램으로 결제하고, 운영자가 입금부터 본부 평가 등록까지 안전하게 관리하도록 한다.

핵심 여정은 다음과 같다.

`콜백 완료 → 상품 확정 → 결제 안내 이메일 → 무통장입금 → 관리자 입금 확인 → 본부 평가 링크 발급 → 고객 본부 등록 → 평가 진행 → 3시간 집중 컨설팅`

초기에는 국내 PG를 연결하지 않는다. 카드정보를 수집하지 않고, 관리자 CRM과 Resend 이메일을 사용해 1인 운영에 필요한 최소 기능만 제공한다.

## 2. 상품 정책

Career Direct Korea는 평가 검사만 별도 판매하지 않는다. 본부의 셀프서비스 평가는 본부가 직접 제공하며, Career Direct Korea의 판매 상품은 컨설턴트가 해석과 실행계획을 함께 제공하는 통합 패키지로 제한한다.

### 2.1 판매 상품

| 상품 | 적용 기준 | 공급가 | VAT | 고객 결제금액 |
|---|---|---:|---:|---:|
| 청년 통합 패키지 | 만 15~28세, 재학 여부 무관 | 350,000원 | 35,000원 | 385,000원 |
| 성인 통합 패키지 | 만 29세 이상 | 450,000원 | 45,000원 | 495,000원 |

두 상품 모두 다음을 포함한다.

- Career Direct 온라인 평가
- 상세 보고서
- 3시간 연속 1회 집중 해석 컨설팅
- 인터랙티브 실행계획 수립
- 필요한 후속 자료 안내

웹사이트와 이메일에는 VAT 포함 최종 결제금액을 우선 표시하고 공급가와 VAT를 함께 구분한다.

### 2.2 가격·할인 원칙

- 위 금액을 상시 정상가로 사용한다.
- 평가 부분만 별도 구매하는 가격이나 CTA를 Career Direct Korea 구매 경로에 표시하지 않는다.
- 초기에는 3일 결제 할인이나 카운트다운 프로모션을 사용하지 않는다.
- 향후 가격을 변경해도 이미 발송된 고객의 주문 스냅샷은 변경하지 않는다.

## 3. 운영 방식

### 3.1 CRM 결제 안내형

관리자가 콜백 상세 화면에서 상품을 선택하고 결제 안내를 발송한다. 공개 주문 페이지나 고객용 상품 선택 페이지는 만들지 않는다.

관리 입력:

- 상품: 청년 또는 성인
- 입금자명
- 증빙 유형: 현금영수증 / 세금계산서 / 미신청
- 필요한 경우 관리자 메모

시스템 계산:

- 공급가, VAT, 최종 결제금액
- 결제 안내 발송 일시
- 입금기한: 발송 시점부터 정확히 72시간
- 기한 경과 여부

### 3.2 결제 상태

- `not_started` — 결제 안내 전
- `awaiting_payment` — 결제 안내 발송, 입금 대기
- `paid` — 관리자 입금 확인
- `cancelled` — 결제 또는 진행 취소
- `refund_pending` — 환불액 확정, 은행 처리 대기
- `refunded` — 환불 완료

입금기한 경과는 별도 결제 상태로 만들지 않고 `awaiting_payment`와 기한을 비교해 화면에 강조한다. 기한이 지나도 자동 취소하지 않는다.

### 3.3 평가 진행 상태

- `not_issued` — 본부 평가 링크 미발급
- `link_issued` — 관리자가 본부 시스템에서 링크 발급
- `registered` — 고객이 본부 사이트에 등록
- `assessment_in_progress` — 평가 진행
- `assessment_completed` — 평가 완료
- `consultation_scheduled` — 3시간 컨설팅 일정 확정
- `consultation_completed` — 컨설팅 완료

평가 링크 URL은 Career Direct 본부가 고객에게 직접 발송한다. Career Direct Korea DB에는 링크 원문을 저장하지 않고 발급·등록·진행 상태와 시각만 기록한다.

## 4. 결제 안내 이메일

이메일에는 다음을 포함한다.

- 확정된 통합 패키지명과 적용 연령
- 포함 서비스
- 공급가, VAT, 최종 입금금액
- 입금기한의 한국시간 날짜·시각
- 은행명, 예금주, 계좌번호
- 입금자명이 신청자와 다를 경우 회신 요청
- 증빙 신청 방법
- 본부 등록 전후 환불 기준 요약
- 입금 확인 후 관리자가 평가 진행을 시작한다는 안내

계좌정보는 코드, Git, DB에 저장하지 않는다. 다음 Vercel 환경변수에서 읽는다.

- `PAYMENT_BANK_NAME`
- `PAYMENT_BANK_ACCOUNT`
- `PAYMENT_BANK_HOLDER`

결제 안내 이메일은 서비스 메시지다. 마케팅 수신 동의와 무관하며 광고성 제목·콘텐츠를 포함하지 않는다.

자동 결제 독촉 이메일은 초기 범위에서 제외한다. 관리자가 CRM의 기한 경과 표시를 확인한 뒤 결제 안내를 재발송하거나 기한을 연장·취소한다.

## 5. 입금 확인과 증빙

### 5.1 입금 확인

운영자가 은행에서 입금을 직접 확인한 후 CRM에서 `입금 확인`을 실행한다.

기록:

- 실제 입금자명
- 입금 확인 일시
- 확인한 관리자 작업 시각
- 결제 확인 이메일 발송 상태

고객이나 공개 API는 결제 상태를 변경할 수 없다. 결제 확인 이메일에는 입금 완료, 선택 상품과 금액, 본부 평가 링크가 별도 이메일로 발송될 예정이라는 안내를 포함한다.

### 5.2 증빙

- 개인 고객: 등록 휴대전화 번호로 소득공제용 현금영수증 발행 여부를 선택한다.
- 사업자 고객: 결제 안내 이메일에 사업자등록증과 세금계산서 수신 이메일을 회신한다.
- 미신청 고객: 증빙 미신청으로 기록한다.

CRM에는 증빙 유형, 발행 상태, 발행 완료 시각만 저장한다. 주민등록번호, 사업자등록증 원본, 현금영수증 식별번호 원문은 저장하지 않는다.

증빙 상태:

- `not_requested`
- `requested`
- `issued`

## 6. 평가 링크와 본부 등록

입금 확인 후 운영자는 Career Direct 본부 시스템에서 고객의 평가 링크를 발급한다. 본부가 고객에게 링크를 직접 이메일로 전송한다.

관리자 CRM 동작:

1. `평가 링크 발급 완료` — 시각 기록
2. 고객의 본부 등록 여부 확인
3. `본부 등록 완료` — 시각 기록 및 환불 가능액 변경
4. 평가 진행·완료 상태 갱신
5. 3시간 컨설팅 일정 확정

본부 등록 완료는 환불 계산의 중요한 기준이므로 관리자가 실제 등록을 확인한 뒤에만 수동으로 처리한다.

## 7. 환불 정책

### 7.1 상품 구성 금액

통합 패키지는 고객 화면에서 하나의 상품으로 판매하지만 환불 계산을 위해 다음 구성 금액을 결제 안내와 환불 규정에 명시한다.

| 상품 | 평가·보고서 | 3시간 컨설팅 | 합계 |
|---|---:|---:|---:|
| 청년 통합 패키지 | 165,000원 | 220,000원 | 385,000원 |
| 성인 통합 패키지 | 165,000원 | 330,000원 | 495,000원 |

모든 금액은 VAT 포함이다.

### 7.2 본부 등록 전후

- 결제 후 본부 평가 링크 발송 전: 전액 환불
- 평가 링크 발송 후 14일 이내이며 본부 등록 전: 링크 취소 후 전액 환불
- 고객이 본부 사이트에 등록한 이후: 평가·보고서 부분 165,000원 환불 불가
- 본부 등록 후 컨설팅 시작 전: 컨설팅 부분을 아래 일정 기준에 따라 환불
- 회사 사정으로 서비스를 제공하지 못한 경우: 미제공 부분 환불 또는 고객 동의 후 보충 제공

본부 사이트 등록 시점부터 평가 부분의 제공이 시작되고 환불이 제한된다는 사실을 결제 안내에서 명확히 고지한다.

### 7.3 컨설팅 변경·취소

- 시작 48시간 전까지 첫 일정 변경: 1회 무료
- 두 번째 변경부터: 컨설팅 금액의 10% 변경 수수료
  - 청년 22,000원
  - 성인 33,000원
- 시작 48시간 이내 변경: 첫 변경 여부와 무관하게 같은 10% 수수료
- 천재지변, 입원 등 불가피한 사유: 운영자 확인 후 수수료 면제 가능
- 변경된 컨설팅은 원래 예정일로부터 60일 이내에 완료

컨설팅 취소 환불:

| 취소 시점 | 청년 환불액 | 성인 환불액 |
|---|---:|---:|
| 시작 48시간 전까지 | 220,000원 | 330,000원 |
| 시작 48시간 이내 | 198,000원 | 297,000원 |
| 당일 노쇼 | 198,000원 | 297,000원 |

48시간 이내 취소와 노쇼는 컨설팅 금액의 10%만 공제한다. 전액 몰수하지 않는다.

### 7.4 컨설팅 시작 후

- 3시간 집중 컨설팅이 시작되면 컨설팅 서비스가 개시된 것으로 본다.
- 고객 사정으로 중단하면 컨설팅 부분은 원칙적으로 환불하지 않는다.
- 회사 사정으로 완료하지 못하면 고객이 보충 일정을 선택하지 않는 경우 미제공 시간을 환불한다.
- 미제공 시간은 30분 단위로 계산한다.
  - 청년: 30분당 36,667원, 마지막 정산에서 원 단위 차이 조정
  - 성인: 30분당 55,000원

### 7.5 환불 처리

- 관리자가 시스템 제안 환불액과 사유를 확인한다.
- 실제 환불은 은행에서 수동 처리한다.
- CRM에는 환불액, 사유 코드, 처리 완료 시각만 저장한다.
- 고객 계좌번호는 CRM에 저장하지 않고 안전한 별도 회신으로 확인한다.
- 환불 확정 후 3영업일 이내 처리하고 이메일로 결과를 안내한다.

## 8. 데이터 모델

기존 `assessment_callback_requests`와 연결된 결제 레코드를 별도 테이블로 둔다. 신청 행에 모든 결제 정보를 추가하지 않는다.

주요 데이터:

- 콜백 신청 ID
- 상품 코드와 상품명 스냅샷
- 적용 연령 기준
- 공급가·VAT·총액 스냅샷
- 평가·보고서·컨설팅 구성 금액 스냅샷
- 결제 상태
- 안내 발송·입금기한·입금 확인 시각
- 실제 입금자명
- 증빙 유형·상태·발행 완료 시각
- 평가 진행 상태와 각 상태 변경 시각
- 환불 상태·제안액·확정액·사유·완료 시각
- 결제·환불 이메일 상태와 안전한 오류 코드
- 생성·수정 시각

한 콜백 신청에는 하나의 활성 결제 레코드만 둔다. 취소 후 다른 상품으로 다시 시작하면 기존 레코드를 덮어쓰지 않고 새 버전을 만든다.

## 9. 관리자 CRM

콜백 상세 화면에 `결제 및 평가 진행` 영역을 추가한다.

기능:

- 상품 선택과 금액 미리보기
- 결제 안내 이메일 발송
- 72시간 기한과 기한 경과 표시
- 입금자명 입력과 입금 확인
- 증빙 요청·발행 완료
- 평가 링크 발급·본부 등록·평가 진행·완료 상태 변경
- 환불 가능액 계산과 환불 대기·완료 기록
- 이메일 실패 재발송

파괴적 상태 변경에는 확인 단계를 둔다. `본부 등록 완료`, `환불 완료`, `취소`는 실수로 되돌릴 수 없도록 현재 상태와 영향을 명확히 표시한다.

## 10. 이메일

발송 종류:

- 결제 안내
- 결제 안내 재발송
- 입금 확인
- 환불 접수
- 환불 완료

본부 평가 링크는 Career Direct Korea 이메일에 포함하지 않는다. 링크 발급 완료 후에는 고객이 본부 발신 이메일을 확인하도록 안내한다.

이메일 발송 실패는 결제·입금·환불 상태를 롤백하지 않는다. 관리자 화면에 실패 상태와 재발송 기능을 제공한다.

## 11. 분석

서버 전용 익명 이벤트:

- `payment_instruction_sent`
- `payment_confirmed`
- `assessment_link_issued`
- `assessment_registered`
- `assessment_completed`
- `consultation_completed`
- `payment_refunded`

분석 이벤트에는 신청 ID, 이름, 이메일, 전화번호, 입금자명, 금액 증빙 정보 또는 계좌정보를 저장하지 않는다. 상품 코드와 유입 UTM만 집계 가능한 비식별 속성으로 사용한다.

## 12. 보안과 개인정보

- 모든 결제·평가 상태 변경 API는 관리자 인증과 동일 Origin을 요구한다.
- 공개 결제 완료 API를 만들지 않는다.
- 은행 계좌정보는 Vercel 환경변수에서 이메일 생성 시에만 읽는다.
- 로그에 계좌번호, 입금자명, 고객 연락처, 증빙 정보, 환불 계좌를 출력하지 않는다.
- 사업자등록증과 고객 계좌번호는 DB에 저장하지 않는다.
- 가격과 환불액은 클라이언트 입력을 신뢰하지 않고 서버의 상품 정책과 저장된 스냅샷으로 계산한다.
- 결제 상태 변경은 현재 상태를 조건으로 원자적으로 처리해 중복 클릭과 경쟁 요청을 막는다.

## 13. 오류 처리

- 계좌 환경변수가 없으면 결제 안내를 발송하지 않고 관리자에게 설정 오류를 표시한다.
- 결제 안내 이메일 실패 시 주문은 유지하고 `발송 실패`로 표시한다.
- 입금 확인 중복 클릭은 결제 확인 이메일을 중복 발송하지 않는다.
- 기한 경과는 자동 취소·환불하지 않는다.
- 본부 미등록 상태를 등록 완료로 바꾸기 전 확인 문구를 표시한다.
- 환불액은 시스템이 제안하지만 관리자가 최종 확인하며, 허용 범위를 넘는 값은 저장하지 않는다.
- DB 오류는 성공으로 표시하지 않고 이전 상태를 유지한다.
