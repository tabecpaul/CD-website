# Meta Pixel 동의 기반 전환 측정 설계

## 목적

Career Direct Korea 광고 유입의 성과를 Meta에서 측정하되, 방문자의 선택권을 보장하고 랜딩페이지 전환을 방해하지 않는다.

## 결정 사항

- Meta Pixel ID는 `NEXT_PUBLIC_META_PIXEL_ID` 환경변수로 관리한다.
- Meta Pixel은 방문자가 선택적 분석·광고 도구 사용에 동의한 뒤에만 로드한다.
- 동의하지 않거나 아직 선택하지 않은 방문자에게는 Meta 스크립트와 이벤트를 전송하지 않는다.
- 동의 여부와 관계없이 자가진단 PDF 신청, 콜백 신청 및 사이트의 모든 핵심 기능을 이용할 수 있다.
- 이름, 이메일, 전화번호와 고급 매칭 정보는 Meta에 보내지 않는다.
- 기존의 개인정보 최소화형 자체 전환 분석은 Meta 동의와 분리해 유지한다.

## 사용자 경험

첫 방문 시 화면 하단에 콘텐츠와 CTA를 가리지 않는 작은 배너를 표시한다.

문구:

> 더 나은 이용 경험과 광고 성과 측정을 위해 선택적 분석 도구를 사용합니다. 허용하지 않아도 모든 서비스를 이용할 수 있습니다.

기본 선택지는 다음 두 개만 노출한다.

- `필수 항목만`: Meta Pixel을 로드하지 않고 배너를 닫는다.
- `모두 허용`: Meta Pixel을 로드하고 측정을 시작한다.

세부 사항은 `자세히 보기` 링크로 개인정보처리방침에 연결한다. 모바일 배너는 화면 높이의 약 15% 이내를 목표로 하며, 사용자가 한 번 선택하면 다시 표시하지 않는다. 개인정보처리방침에는 선택을 변경할 수 있는 `쿠키 설정 변경` 기능을 제공한다.

## 동의 상태

- 상태 버전은 `cdk_consent_v1`로 관리한다.
- 값은 `essential` 또는 `all` 두 종류만 사용한다.
- 브라우저 저장소의 값이 없거나 유효하지 않으면 미선택 상태로 간주한다.
- 버전이 변경되면 기존 선택을 무효화하고 새 정책에 대한 선택을 다시 요청할 수 있다.

## Meta 이벤트

| 사용자 행동 | Meta 표준 이벤트 | 발생 조건 |
|---|---|---|
| 페이지 방문 | `PageView` | `all` 동의 후 Pixel 초기화 및 클라이언트 경로 변경 |
| 자가진단 PDF 신청 | `Lead` | `/api/lead-magnet` 성공 응답 이후 |
| 20분 무료 콜백 신청 | `Schedule` | `/api/assessment-callback` 성공 응답 이후 |

모든 이벤트 함수는 동의가 없거나 Pixel이 준비되지 않은 경우 조용히 종료한다. 신청 API의 실패, 입력 검증 실패 또는 중복 버튼 클릭은 Meta 전환으로 기록하지 않는다.

## 데이터 최소화

Meta에는 표준 이벤트 이름과 측정에 필요한 페이지 문맥만 전달한다. 다음 정보는 전달하지 않는다.

- 이름, 이메일, 전화번호
- 상담 내용과 선택한 진로 고민
- 성별, 연령대, 혼인 여부
- 결제·평가·코칭 운영 상태
- 자체 익명 방문자 ID

UTM 정보는 Career Direct Korea 자체 분석에서 계속 관리한다. MVP에서는 Meta 고급 매칭과 Conversions API를 사용하지 않는다.

## 구성 요소

1. 전역 동의 배너와 동의 상태 저장 모듈
2. 동의 후에만 Pixel을 초기화하는 전역 로더
3. 동의 상태를 확인하는 Meta 이벤트 헬퍼
4. PDF 신청 성공 지점의 `Lead` 연결
5. 콜백 신청 성공 지점의 `Schedule` 연결
6. 개인정보처리방침의 설명 및 설정 변경 기능

## 오류 및 안전 동작

- Pixel ID가 없으면 사이트 기능은 정상 작동하고 Meta 측정만 비활성화한다.
- Meta 네트워크 요청이 차단되거나 실패해도 신청 흐름과 자체 분석에는 영향을 주지 않는다.
- 브라우저 추적 방지 또는 광고 차단기를 우회하지 않는다.
- 동의를 철회하면 이후 Meta 이벤트 전송을 즉시 중단한다.

## 검증 기준

- 미선택 및 `essential` 상태에서 Meta 스크립트·네트워크 요청이 발생하지 않는다.
- `all` 선택 후 Pixel이 한 번만 초기화되고 `PageView`가 기록된다.
- PDF 신청 성공 시에만 `Lead`가 한 번 발생한다.
- 콜백 신청 성공 시에만 `Schedule`이 한 번 발생한다.
- 거부 상태에서도 PDF와 콜백 신청이 정상 완료된다.
- 모바일에서 배너가 주요 제목과 CTA를 가리지 않는다.
- 새로고침 후 선택 상태가 유지되고 개인정보처리방침에서 변경할 수 있다.
- Meta Events Manager의 테스트 이벤트 화면에서 승인된 세 이벤트를 확인할 수 있다.

## 향후 확장

광고 규모와 데이터 품질 요구가 커지면 별도 검토 후 Meta Conversions API를 추가할 수 있다. 이 경우 브라우저·서버 이벤트 중복 제거, 고지 범위, 보유 기간과 전송 데이터 항목을 새 설계로 승인받는다.
