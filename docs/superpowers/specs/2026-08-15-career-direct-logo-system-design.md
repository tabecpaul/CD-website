# Career Direct 공식 로고 적용 설계

## 목적

Career Direct 본부가 제공한 `Living by Design` 로고 자산을 웹사이트의 공식 브랜드 로고로 사용한다. 현재 사이트의 남색·크림·흰색 배경과 충분한 대비를 확보하고, 모든 로고 사용처에서 같은 선택 규칙을 적용한다. 한국 사이트 식별을 위한 `Korea` 텍스트는 로고 옆에 유지한다.

## 자산 관리

- 제공된 PNG 원본 7개를 `apps/www/public/brand/career-direct/` 아래에 원본 파일명으로 보관한다.
- 화면에서는 다음 두 자산을 기본으로 사용한다.
  - 밝은 배경: `CD_LivingBD_2CP_RGB.png`
  - 어두운 배경: `CD_LivingBD_1CR_White.png`
- 나머지 단색·보조 색상 자산도 향후 인쇄물·특수 배경에 사용할 수 있도록 함께 보관한다.
- 이미지 비율은 원본 1824×510을 유지하고 CSS로 찌그러뜨리지 않는다.

## 공용 컴포넌트

`CareerDirectLogo` 공용 컴포넌트를 추가한다.

- `variant="color"`: 흰색·크림색처럼 밝은 배경에서 컬러 로고를 표시한다.
- `variant="white"`: 남색처럼 어두운 배경에서 화이트 로고를 표시한다.
- `Korea` 텍스트는 이미지 바깥의 실제 텍스트로 유지해 선명도와 접근성을 확보한다.
- `Korea` 색상은 컬러형에서 남색, 화이트형에서 금색을 기본으로 한다.
- 크기와 우선 로딩 여부를 사용처가 조정할 수 있게 하되, 자산 선택과 기본 정렬은 컴포넌트가 담당한다.
- 이미지 대체 텍스트는 `Career Direct`로 통일하고 홈 링크에는 `Career Direct Korea 홈` 접근성 이름을 제공한다.

## 적용 범위

- `PageHeader`: 크림 배경에 컬러형 로고와 남색 `Korea`를 사용한다.
- 일반 `Footer`: 남색 배경에 화이트형 로고와 금색 `Korea`를 사용한다. 기존 크림색 배경판은 제거한다.
- `OfficialFooter`: 남색 배경에 화이트형 로고와 금색 `Korea`를 사용한다. 기존 크림색 배경판은 제거한다.
- `CareerCheckLanding` 헤더: 밝은 배경에 컬러형 로고와 남색 `Korea`를 사용한다.
- 코드 검색으로 확인되는 기존 `/career-direct-logo.png` 직접 사용은 모두 공용 컴포넌트로 교체한다.
- 문서 본문에서 텍스트로 언급되는 `Career Direct`와 자격증·OG 이미지 같은 별도 목적의 이미지는 변경하지 않는다.

## 레이아웃과 반응형 기준

- 로고는 원본 종횡비를 유지하며 영역에 따라 약 28–34px 높이로 표시한다.
- `Korea`는 로고와 시각적으로 한 묶음이 되도록 일정한 간격과 수직 정렬을 적용한다.
- 모바일에서도 로고와 `Korea`가 겹치거나 줄바꿈되지 않게 한다.
- 푸터에서는 배경판을 제거한 뒤에도 화이트 로고가 남색 배경에서 충분한 대비를 유지해야 한다.
- 로고 주변에 다른 텍스트나 테두리가 과도하게 붙지 않도록 최소 여백을 유지한다.

## 검증

- 제공된 7개 PNG가 모두 지정 경로에 복사됐는지 확인한다.
- 기존 `/career-direct-logo.png` 직접 참조가 남아 있지 않은지 검색한다.
- 린트와 TypeScript/프로덕션 컴파일을 실행한다.
- 주요 헤더와 두 종류의 푸터를 모바일·데스크톱 화면에서 확인한다.
- 밝은 배경에는 컬러형, 남색 배경에는 화이트형이 표시되는지 확인한다.
- 기존 사용자 미추적 파일과 다른 작업 결과물은 수정하거나 커밋하지 않는다.

## 완료 기준

사이트의 모든 실제 로고 사용처가 공식 `Living by Design` 자산을 사용하며, 배경 대비에 맞는 색상 버전과 `Korea` 표기가 일관되게 표시된다. 기존 페이지의 탐색 동작과 반응형 레이아웃에는 회귀가 없어야 한다.
