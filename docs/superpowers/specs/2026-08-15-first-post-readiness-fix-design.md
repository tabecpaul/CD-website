# 첫 게시물 발행 준비 보정 설계

## 목표

2026년 8월 17일 첫 게시물인 `why-career-anxiety-and-burnout`을 네이버 블로그, 페이스북, 인스타그램, Threads에서 실제 게시 가능한 상태로 만든다.

## 1. 관리자 저장 출처 검증

현재 관리자 페이지는 `www.careerdirect.kr`에서도 제공되지만 쓰기 API는 `NEXT_PUBLIC_SITE_URL`인 `start.careerdirect.kr`만 허용해 403을 반환한다.

공통 서버 유틸리티가 요청 `Origin`을 다음 허용 목록과 비교하도록 변경한다.

- `NEXT_PUBLIC_SITE_URL`의 origin
- `NEXT_PUBLIC_OFFICIAL_SITE_URL`의 origin
- 운영 기본값 `https://start.careerdirect.kr`, `https://www.careerdirect.kr`

정확히 일치하는 HTTPS origin만 허용하며 임의 하위 도메인이나 와일드카드는 허용하지 않는다. 콘텐츠 상태·성과 API에 먼저 적용하고 동일한 문제가 있는 관리자 콜백 쓰기 API도 같은 유틸리티를 사용해 회귀를 막는다.

## 2. 첫 게시물 문안 교정

인스타그램 문안의 `Facebook 원문`, `Facebook CTA` 표기를 인스타그램 용도에 맞게 교정한다. Facebook 문안과 각 채널 UTM은 유지한다. 생성 카탈로그와 원본 캠페인 문안을 함께 갱신해 다음 시드에서도 동일한 결과가 나오도록 한다.

## 3. 카드 이미지 산출물

기존 카드뉴스 8장 문안을 사용해 1080×1080 PNG 8장을 만든다. Career Direct Korea의 네이비·틸·오프화이트 색상과 로고를 사용하고, 모바일에서 읽을 수 있는 큰 제목과 짧은 본문 구조를 유지한다.

산출물은 첫 게시물 전용 폴더에 저장하고 ZIP에도 포함한다. Canva에서 후속 편집이 가능하도록 페이지 단위 편집 원본도 함께 제공한다. 대체 텍스트는 기존 검수 문안을 유지한다.

## 4. 검증과 운영 전환

1. 린트·타입 검사와 관리자 origin 단위 테스트를 통과한다.
2. 공식 원문과 네 UTM 링크가 HTTP 200인지 재확인한다.
3. 카드 이미지 8장의 크기·텍스트 잘림·로고 대비를 확인한다.
4. 배포 후 `www` 관리자에서 상태 저장이 성공하는지 확인한다.
5. 네 채널을 `준비 완료`로 전환하고 관리자 목록에서 상태를 재확인한다.
6. 준비 알림은 중복 방지 기록을 존중하며, 실제 후보가 있을 때만 발송한다.

## 안전 조건

- 기존 게시 URL과 성과 데이터는 변경하지 않는다.
- 사용자 미추적 파일과 기존 산출물은 삭제하거나 덮어쓰지 않는다.
- 실제 이미지가 완성되기 전에는 인스타그램과 페이스북을 준비 완료로 변경하지 않는다.
