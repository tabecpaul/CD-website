# 청년 직장인 리드 마그넷 개인정보·이메일 동의 결정

- 상태: 제품 정책 승인, 출시 전 법률 검토 필요
- 승인일: 2026-08-07
- 적용 버전: `lead-magnet-consent-ko-v1.0`
- 적용 범위: `/career-check` 무료 진로방향 자가진단 PDF 신청
- 대상: 만 14세 이상 사용자

## 결정 요약

PDF 제공에 필요한 개인정보 처리와 2·4·6일 차 코칭·Career Direct 안내 이메일을 서로 다른 목적으로 처리한다. 첫 번째는 PDF 신청 처리에 필요한 필수 항목이고, 두 번째는 사용자가 선택할 수 있는 광고성 정보 수신 동의다.

- 수집 항목은 이메일 주소와 신청·동의 증적에 필요한 최소 정보로 제한한다.
- 선택 동의 체크박스는 기본 선택하지 않는다.
- 선택 동의를 거부해도 PDF 신청과 다운로드를 제한하지 않는다.
- PDF 전달 이메일에는 평가·상담 등 홍보 CTA를 넣지 않는다.
- 코칭 이메일 3회는 선택 동의자에게만 2일, 4일, 6일 차에 발송한다.
- 모든 코칭 이메일은 광고성 정보 표시와 즉시 작동하는 수신 거부 수단을 제공한다.
- 이메일 주소를 광고 플랫폼이나 외부 분석 도구의 식별자로 전송하지 않는다.

개인정보 보호법은 동의를 받을 때 목적별 동의 사항을 구분해 명확하게 알리도록 하고, 선택적 또는 홍보 목적 동의를 거부했다는 이유로 서비스 제공을 거부하지 못하도록 정한다. 정보통신망법상 영리 목적 광고성 이메일은 원칙적으로 사전 수신동의와 수신 거부 수단이 필요하다.

## 폼에 표시할 문구

### 필수 체크박스

> [필수] 무료 PDF 제공을 위한 개인정보 수집·이용에 동의합니다.

체크박스 바로 옆에 `자세히 보기`를 제공하며, 펼친 영역에는 다음 내용을 표시한다.

| 고지 항목 | 내용 |
| --- | --- |
| 수집·이용 목적 | 무료 「진로방향 자가진단 PDF」 신청 처리, 다운로드 링크 발급·재발급, 전달 오류 대응 |
| 수집 항목 | 이메일 주소, 신청·동의 시각, 동의 정책 버전, 신청 페이지·유입경로, 발송·다운로드 상태 |
| 보유·이용 기간 | 신청일로부터 30일 또는 삭제 요청 처리 시점 중 먼저 도래한 때까지. 관계 법령에 따라 별도 보존이 필요한 정보는 해당 기간 동안 분리 보관 |
| 동의 거부 권리와 영향 | 동의를 거부할 수 있으나, 이메일로 PDF 링크를 제공하기 위해 필요한 정보이므로 무료 PDF 신청은 완료할 수 없음 |

필수 동의에는 2·4·6일 차 코칭 이메일, 평가 권유, 상담 권유 또는 일반 뉴스레터 발송 권한이 포함되지 않는다.

### 선택 체크박스

> [선택] 격일 3회 진로 코칭 및 Career Direct 평가·상담 안내 이메일 수신에 동의합니다. (2·4·6일 차 발송, 언제든 수신 거부)

체크박스 바로 옆에 `자세히 보기`를 제공하며, 펼친 영역에는 다음 내용을 표시한다.

| 고지 항목 | 내용 |
| --- | --- |
| 처리 목적 | 진로 성찰 질문과 행동 제안 3회, Career Direct 평가 및 컨설턴트 상담 안내 |
| 이용 항목 | 이메일 주소, 선택 동의·철회 시각, 이메일 전달·반송·열람·클릭·수신 거부 상태 |
| 발송 일정 | 신청 후 2일, 4일, 6일 차에 각 1회. 자료 전달 이메일은 3회에 포함하지 않음 |
| 보유·이용 기간 | 신청일로부터 30일 또는 수신 동의 철회·삭제 요청 처리 시점 중 먼저 도래한 때까지 |
| 동의 거부 권리와 영향 | 동의를 거부해도 무료 PDF 신청과 다운로드에는 영향이 없음 |

선택 동의는 기본값을 `false`로 하고 필수 동의와 별도의 동의 레코드로 저장한다. `전체 동의`를 추가하더라도 필수·선택 상태와 상세 내용을 각각 확인할 수 있어야 한다.

### 제출 버튼과 보조 문구

- 버튼: `무료 진로방향 자가진단 받기`
- 버튼 아래: `PDF는 신청 후 바로 다운로드할 수 있으며 입력한 이메일로도 보내드립니다.`
- 선택 동의 안내: `코칭 이메일 수신은 선택이며, 동의하지 않아도 PDF를 받을 수 있습니다.`
- 정책 링크: `개인정보처리방침`

## 검증·오류 문구

| 상황 | 사용자 문구 |
| --- | --- |
| 이메일 누락 | 이메일 주소를 입력해 주세요. |
| 이메일 형식 오류 | 이메일 주소 형식을 확인해 주세요. |
| 필수 동의 누락 | 무료 PDF 제공을 위한 개인정보 수집·이용 동의가 필요합니다. |
| 선택 동의 미체크 | 오류를 표시하지 않고 PDF 신청을 정상 처리합니다. |
| 중복 신청·동의 유지 | 이미 신청한 이메일입니다. 새 다운로드 링크를 보내드렸습니다. |
| 과거 수신 거부·선택 미동의 | PDF만 전달하고 코칭 이메일은 발송하지 않습니다. |
| 과거 수신 거부·새 선택 동의 | 새 동의 시각과 버전을 기록하고 이번 3회 여정만 다시 시작합니다. |
| 저장 실패 | 신청을 완료하지 못했습니다. 잠시 후 다시 시도해 주세요. |

중복 신청 안내는 실제 PDF 재발송 요청이 성공한 경우에만 사용한다. 사용자 존재 여부를 악용한 이메일 열거 공격을 막기 위해 외부 응답은 동일한 성공 형태로 반환할 수 있다.

## 이메일 분류와 표시

### 신청 즉시: PDF 전달 메일

- 성격: 사용자가 요청한 자료를 제공하는 서비스 메시지
- 포함: PDF 다운로드 링크, 링크 만료일, 재발급 방법, 문의처
- 제외: Career Direct 평가·상담 CTA, 할인, 이벤트, 다른 상품 홍보
- 수신 거부: 서비스 메시지 자체에는 광고 수신 거부 대신 개인정보 문의·삭제 요청 경로를 제공

### 2·4·6일 차: 코칭 이메일

- 성격: 진로 코칭 콘텐츠와 Career Direct 안내를 포함할 수 있는 광고성 정보
- 대상: 선택 동의가 현재 유효한 사용자만
- 제목: 관계 법령과 KISA 가이드에 맞는 광고성 정보 표시 사용
- 본문: 발신자 명칭과 연락처, 수신동의 근거, 무료 수신 거부 링크를 명확히 표시
- 수신 거부: 로그인이나 추가 정보 입력 없이 한 번의 명확한 행동으로 처리
- 철회 우선순위: 발송 직전 최신 철회 상태를 확인하고 예약 이벤트보다 철회를 우선 적용

열람 추적 픽셀은 MVP 기본값으로 사용하지 않는다. 클릭 측정은 개인을 직접 식별하지 않는 내부 이벤트 식별자를 사용하며, 운영 필요성이 확정된 링크에만 적용한다.

## 보유·파기 규칙

### 30일 보유를 선택한 이유

3회 이메일 여정이 신청 후 6일 안에 끝나므로, 30일은 전달 장애, 다운로드 링크 재발급, 반송·신고 처리와 사용자 문의에 대응하기 위한 제한된 운영 기간이다. 장기 뉴스레터나 CRM 육성은 이번 동의 범위에 포함하지 않는다.

### 파기 대상

30일이 지나면 법적 보존 필요성이 없는 다음 정보를 삭제하거나 비식별화한다.

- 이메일 원문과 정규화 이메일
- 유효한 다운로드 권한과 토큰
- 이메일 주소에 직접 연결된 열람·클릭·전달 상태
- 이메일 주소에 직접 연결된 유입정보와 세션 연결값

다음 정보는 개인을 다시 식별할 수 없도록 집계한 뒤 성과 분석에 사용할 수 있다.

- 고유 방문 대비 유효 신청 수
- PDF 다운로드 수
- 발송·반송·수신 거부의 집계값
- 평가·상담 관심 클릭의 집계값

삭제 요청이 접수되면 법적 보존 의무가 없는 원본 데이터를 10일 이내에 처리하는 것을 내부 운영 목표로 한다. 실제 법정 처리기한과 예외는 출시 전 법률 검토에서 확정한다.

## 동의 증적

각 목적의 동의는 다음 값을 분리해 저장한다.

- 내부 리드 식별자
- 목적 코드: `pdf_delivery` 또는 `coaching_marketing`
- 동의 여부
- 동의·철회 시각
- 정책 버전 `lead-magnet-consent-ko-v1.0`
- 폼 버전과 표시 언어
- 고지문 내용의 해시
- 신청 경로와 최소한의 유입정보
- 서버가 확인한 요청 식별자

로그와 분석 이벤트에는 이메일 원문을 기록하지 않는다. IP 주소와 User-Agent의 저장은 남용 방지에 필요한 범위와 기간이 확정된 경우에만 별도 고지 후 적용한다.

## 사용자 권리와 연락 경로

개인정보처리방침과 이메일에는 다음 기능 또는 연락 경로를 제공한다.

- 개인정보 열람 요청
- 이메일 주소 정정 요청
- 개인정보 삭제 요청
- 마케팅 수신 동의 철회
- 만료된 PDF 링크 재발급 요청
- 개인정보 보호 담당자 또는 공식 문의 이메일

공개 도메인은 `https://www.careerdirect.kr`, 공식 사무실 주소는 `경기도 의왕시 오봉산단1로 12, 에이스비전 21 10층 1012호`로 확정한다. 개인정보처리자의 법적 명칭, 담당자 명칭, 공식 이메일·전화번호와 사업자 정보는 실제 운영 주체 확인 후 임시 문구 없이 입력한다. 이 값이 없으면 운영 배포하지 않는다.
