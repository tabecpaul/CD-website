# 신앙과 소명 게시 체크리스트

## 게시 전

- [ ] 발행일·주제·시간이 운영표와 일치한다.
- [ ] 성경의 책·장·절이 구체적으로 표시되어 있다.
- [ ] 개역개정을 기본으로 사용했고 새번역은 보완역본으로 구분했다.
- [ ] 성경 구절이 문맥과 논지를 벗어나지 않는다.
- [ ] Career Direct가 하나님의 뜻이나 소명을 판정한다고 표현하지 않았다.
- [ ] 성격·흥미·재능·가치관과 성령의 은사를 동일시하지 않았다.
- [ ] CTA가 해당 콘텐츠에 지정된 하나뿐이다.
- [ ] 실제 고객 개인정보나 동의받지 않은 사례가 없다.
- [ ] 모바일 화면에 맞게 문단과 줄바꿈을 확인했다.

## 채널별

- [ ] 네이버 원고는 공식 원문의 단순 복제가 아니다.
- [ ] 네이버 하단에 공식 원문, CTA, 컨설턴트 소개가 있다.
- [ ] 카드뉴스는 7~8장이고 각 장의 문안이 한 화면에 적합하다.
- [ ] 인스타그램에는 프로필 링크 안내가 있다.
- [ ] 페이스북에는 본문용 추적 링크가 있다.
- [ ] 카드뉴스 대체 텍스트가 준비되어 있다.
- [ ] Threads는 번호와 마지막 CTA가 분명하다.

## 게시 후

- [ ] 로그아웃 상태에서 게시물과 링크를 확인했다.
- [ ] 링크가 올바른 공식 글 또는 CTA 페이지로 연결된다.
- [ ] 이미지가 잘리지 않고 대체 텍스트가 입력되었다.
- [ ] 24시간 뒤 댓글·저장·공유·링크 클릭을 기록했다.
- [ ] 관리자 전환 분석에 UTM source와 campaign이 잡히는지 확인했다.
