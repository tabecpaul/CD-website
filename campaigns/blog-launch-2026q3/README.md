# Career Direct Korea 블로그 론칭 캠페인

## 목적

공식 블로그의 핵심 글 6편을 네이버 블로그, 인스타그램, 페이스북, 스레드에 2주 동안 순차 배포해 한국 사용자의 검색·공감 유입을 만들고 무료 자가진단 또는 20분 무료 콜백으로 연결합니다.

## 대상

- 진로 방향이 불분명한 청년 직장인
- 이직과 경력 전환을 고민하는 성인
- AI 변화와 번아웃으로 일의 의미를 다시 점검하는 사람

## 운영 원칙

- 공식 사이트 글을 원문으로 유지합니다.
- 네이버 글은 원문의 50~70%를 검색 문체로 재구성합니다.
- 게시물 하나에는 CTA 하나만 사용합니다.
- 인스타그램·페이스북 소재는 공감 인물형 A와 타이포형 B를 교차합니다.
- 첫 2주는 수동 게시하고 성과 확인 후 자동화를 검토합니다.
- 조회수보다 자가진단·콜백 전환과 상담 적합도를 우선 평가합니다.

## 폴더

- `copy/naver-blog`: 네이버 블로그용 원고 6편
- `copy/instagram-facebook.md`: 인스타그램·페이스북 공용 캡션
- `copy/threads.md`: 스레드 연속 글
- `links/campaign-links.csv`: 채널별 원문 및 CTA 추적 링크
- `launch-plan.md`: 게시 일정과 담당 작업
- `checklist.md`: 게시 전후 점검표
