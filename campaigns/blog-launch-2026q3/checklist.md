# 게시 체크리스트

## 게시 전

- [ ] 날짜와 주제가 운영표와 일치한다.
- [ ] 해당 채널의 `tracked_url`을 CSV에서 복사했다.
- [ ] CTA가 글에 지정된 자가진단 또는 콜백 하나뿐이다.
- [ ] 제목과 첫 문단에서 독자의 문제와 글의 효용이 분명하다.
- [ ] 통계와 정의가 공식 출처의 의미를 왜곡하지 않는다.
- [ ] 실제 고객 개인정보나 동의받지 않은 사례가 없다.
- [ ] 맞춤법과 줄바꿈을 모바일 화면에서 확인했다.
- [ ] 공감 인물형 A 또는 타이포형 B 소재가 운영표와 일치한다.

## 채널별

- [ ] 네이버 글은 공식 원문의 문장을 그대로 복제하지 않았다.
- [ ] 네이버 글 하단에 출처와 컨설턴트 소개가 있다.
- [ ] 페이스북 본문에 추적 링크가 있다.
- [ ] 인스타그램에는 `프로필 링크` 안내가 있고 본문 링크에 의존하지 않는다.
- [ ] 스레드는 게시물 순서와 마지막 CTA가 분명하다.

## 게시 후

- [ ] 게시된 링크를 로그아웃 또는 비공개 창에서도 확인했다.
- [ ] 링크가 지정된 공식 글 또는 CTA 페이지로 연결된다.
- [ ] 이미지가 잘리지 않고 대체 텍스트를 입력했다.
- [ ] 24시간 뒤 댓글·저장·공유·링크 클릭을 기록했다.
- [ ] 관리자 전환 분석에 UTM source와 campaign이 잡히는지 확인했다.
