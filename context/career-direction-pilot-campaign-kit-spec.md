# 청년 직장인 진로 방향 파일럿 캠페인 키트 명세

상세 설계 정본: `docs/superpowers/specs/2026-08-10-career-direction-pilot-campaign-kit-design.md`

## 제품 결정

- 1차 CTA는 무료 12페이지 진로 방향 자가진단 PDF다.
- 연결 페이지는 `https://start.careerdirect.kr/career-check`다.
- 중심 소재는 공감 인물형 A와 강한 타이포형 B다.
- 워크북 실물형은 네이버 블로그·리타게팅 보조 소재다.
- 교회·청년부는 신앙·소명 언어를 명시적으로 사용한다.
- 일반 직장인·대학 채널에는 종교 표현을 전면에 두지 않는다.
- 광고 계정 설정, 게시, 비용 집행은 하지 않는다.

## 확정 문구

- 공감 인물형: `왜 열심히 사는데 진로 불안과 번아웃을 느끼나요?`
- 타이포형: `열심히 사는데도 불안한 이유, 방향보다 자기이해가 먼저일 수 있습니다.`
- 워크북형: `성격, 흥미, 재능, 가치관, 4가지 나침반으로 진로 방향을 점검하세요.`
- 교회형: `하나님이 지으신 나를 발견하고 일과 소명의 방향을 분별하세요.`

## 산출물

- Instagram/Facebook 피드·스토리 A/B
- Threads 글 6개·타이포 이미지 2개
- 네이버 블로그 장문 글 2개·대표/본문 이미지
- 교회·대학 A4 PDF와 모바일 공지 이미지
- 채널별 무료·유료 게시 문구
- UTM 링크 CSV
- QR PNG·SVG
- 캠페인 README
- 웹사이트 `utm_content` 수집·저장·분석

## 추적 계약

- `utm_campaign=career_direction_pilot_2026q3`
- source·medium·content 값은 상세 설계 표와 목록을 그대로 사용한다.
- `utm_content`는 소문자 영문, 숫자, underscore로 구성한다.
- 기존 null은 `(none)`으로 표시한다.
- 테스트 데이터 제외 규칙을 유지한다.

## 완료 조건

- 6개 채널에 바로 배포 가능한 파일과 문구가 있다.
- 모든 링크와 QR이 올바른 UTM URL로 연결된다.
- 공감 인물형·타이포형 전환을 대시보드에서 비교할 수 있다.
- 이미지·PDF 렌더링, 타입검사, lint, production build가 통과한다.
